5

A “model 5” setting can be mistaken for “RIFE 5.”

In one widely used third-party VapourSynth port, the numeric choice model 5 selects RIFE 2.3. It is the sixth item in that wrapper’s list, not a version-5 checkpoint. An arXiv “v5” label likewise means the fifth revision of the paper, not a new interpolation model.

“Objectively superior” changes with the footage.

A model can score higher on natural-camera benchmarks and still produce worse anime frames because animation has flat color regions, held drawings, abrupt poses and deliberately non-linear motion.

What public scores can prove

They can compare models on the exact benchmark and hardware used. They cannot prove that an AMV editor will prefer the result on current anime footage.

What an editor actually notices

A single broken face, doubled line or melted hand is more damaging than a small average score improvement across thousands of easy pixels.

Thin hair and face lines wobble or split during fast motion.
A held drawing gains false movement even though the source intentionally stays still.
A smear frame gets “corrected” into a softer image and loses the animator’s intended impact.
Foreground limbs and background pans move at different speeds, so edges tear where one passes the other.
Text, credits and hard subtitles bend because the model treats them as moving picture detail.
!

The upstream maintainer warns against treating one image score as the answer.

Practical-RIFE states that improved PSNR does not consistently match subjective perception. Research on interpolation-specific quality measurement reaches the same practical conclusion: ordinary image scores can disagree with human judgment because they do not fully capture motion over time.

Produced models worth considering

“Produced” here means public code plus pretrained weights. A paper without a usable, redistributable checkpoint cannot become an app option.

Model What the user may gain What blocks a claim of superiority Fit for Ultimate AMV
RIFE 4.25
keep default		 Strong line stability and detail on anime, fast arbitrary-time output, current GPU and CPU paths already work. It will still invent bad frames on large motion, occlusion, held drawings and stylized smears. Best supported production choice today. MIT code and weights.
RIFE 4.26
A/B test		 It is the newest official numbered checkpoint and stays inside the same model family. Upstream still recommends 4.25. There is no matched anime test showing 4.26 wins. Lowest-risk challenger, but a larger number is not enough reason to expose it in the UI.
GMFSS Fortuna
anime challenger		 It was trained specifically for anime and includes a fine-tune using anime motion data. Its project provides no controlled public comparison against Practical-RIFE 4.25. It adds CuPy and an older tested runtime. Best second-family experiment. MIT license, but integration and CPU parity need proof.
IFRNet
efficiency challenger		 Published tests beat the original 2022 RIFE by small margins on several natural-video scores at similar speed, with fewer model parameters. Those tests do not include Practical-RIFE 4.25 and do not establish anime superiority. Credible and MIT-licensed. Worth testing if speed and memory matter more than anime specialization.
AnimeInterp
research reference		 Its design directly targets flat-color regions, line art and very large animation motion. Its public implementation targets very old PyTorch versions and predates current Practical-RIFE models. Useful evidence about anime failure modes; poor production fit for the app’s current runtime.
FILM
large-motion reference		 Designed to handle large movement and licensed permissively. The official stack is TensorFlow-based, older, and not trained specifically as an anime default. Would add a second large machine-learning runtime for an unproven anime gain.
AMT
do not ship		 Its paper reports higher scores than the original RIFE on several standard tests. The released code and models are non-commercial unless separate permission is obtained; the comparison is not against 4.25. Licensing blocks a normal production integration.
GIMM-VFI
do not ship		 Offers arbitrary-time motion modeling and perceptually enhanced checkpoints. Commercial use requires permission. Its own example reports about 7.9 GB at downscaled 2K interpolation on a V100. Heavy, non-commercial by default, and difficult to make equivalent on CPU.
2025–26 diffusion models
watch		 Some produce better large-motion or long-sequence benchmark results. They change the task from a small pairwise model into a much larger video-generation workload; evidence remains mixed by dataset. Research watchlist, not a practical desktop replacement today.

The app already prevents one of the ugliest failures.

When consecutive frames look like a hard cut, the app repeats the source frame instead of asking RIFE to blend unrelated shots. That prevents a brief melted transition no matter which RIFE checkpoint is selected.

A model swap will not fix anime cadence by itself.

When the source repeats a drawing for two or three frames, interpolation can produce more frames without producing more real motion. Removing unintended duplicate frames first, preserving intentional holds, and protecting hard cuts can change the visible result more than moving from one nearby RIFE checkpoint to another.

One bake-off can establish the best model for this app.

Public rankings cannot answer the product question because they do not use this app’s anime clips, output settings, RTX path or CPU fallback.

Recommended decision

Keep 4.25 now. Test 4.26, GMFSS Fortuna and IFRNet before adding any option.

Use 20–30 short clips containing line art, hair, faces, fast pans, rotating cameras, foreground occlusion, smears, held drawings, subtitles, flashes and internal cuts. Render identical timestamps, hide the model names, then score visible failures, blind preference, render speed, peak memory and CPU completion.

Promotion rule A challenger must reduce obvious bad frames without making the normal batch materially slower.
Failure rule One severe face or line failure counts more than a tiny average image-score gain.
UI rule Expose a model only when the user can predict why they would choose it.
