Hardware requirements

The current app is Windows-first and its GPU path is NVIDIA-only. CPU mode works with either AMD or Intel, but scene detection and vocal separation become CPU-bound and take longer.

Short answer Buy an RTX 5060 Ti 16 GB if GPU mode is the goal.

For CPU mode, target a modern 8-core desktop CPU and 32 GB RAM: Ryzen 7 9700X or Core Ultra 7 265K.

What the code actually requires

GPU mode selectedThe backend installs CUDA-enabled PyTorch and the GPU versions of its AI runtimes.
→
NVIDIA CUDA worksPyTorch must report a usable CUDA device. The current install targets CUDA 12.8.
→
Video path acceleratesClip detection uses TransNetV2; H.264, HEVC, and AV1 can use NVIDIA decoding. Other codecs use CPU decoding but still use the GPU model.
AMD and Intel GPUs: the current GPU mode does not use Radeon, Arc, or integrated graphics for the AI path. An AMD or Intel CPU is fine; an AMD or Intel GPU is not a supported replacement for the current CUDA path.

GPU mode: minimum versus recommended

PartMinimum practicalRecommendedWhy it matters
GPURTX 2060 6 GB or newerRTX 5060 Ti 16 GBThe backend needs CUDA through PyTorch. NVIDIA decoding and NVENC are also used by the fast video path and export options.
GPU memory6 GB16 GBThe code does not enforce a VRAM minimum. Six GB is a sensible floor for one job; 16 GB leaves room for BS-RoFormer, background-removal models, GPU export, and concurrent work.
System memory16 GB32 GBThe clip detector buffers a complete low-resolution analysis stream. A 24-minute episode at 24 fps is roughly 128 MiB for the RGB analysis frames before Python, the model, the app, previews, and the OS are counted.
Driver/runtimeWindows x64 NVIDIA driver able to run the app’s CUDA 12.8 PyTorch wheelCurrent Studio driver plus the bundled CUDA 12.8 environmentThe app checks whether CUDA actually imports and runs; having an NVIDIA card or selecting “GPU” in settings is not enough.
Free storage10 GB on SSD20 GB or more on SSDGPU setup downloads large Python wheels and models. Media files and generated exports need additional space.
Important distinction: RTX 2060 is a recommendation for the published minimum, not a hard-coded source check. The current source checks CUDA availability and runtime health rather than rejecting a model by name or VRAM amount. A slower or smaller NVIDIA card may start, but it is outside the safe product target.

CPU mode: AMD and Intel equivalents

TierAMDIntelExpected consequence
Usable floorRyzen 5 5600 / Ryzen 5 7600Core i5-12400F / Core i5-13400Works for occasional episodes, but CPU scene analysis and CPU vocal separation will be noticeably slower.
RecommendedRyzen 7 9700XCore Ultra 7 265KGood sustained throughput for the app while keeping the desktop responsive. Both are in the 8-strong-core-class target; Intel supplies 20 total hybrid cores, while AMD supplies 8 cores and 16 threads.
Good value / existing systemsRyzen 7 7700Core i7-12700KStill a sensible CPU-mode pairing if already owned or available at a good price. It is not necessary to buy a flagship CPU for this workload.
System memory16 GB minimum; 32 GB recommendedMore memory helps when the app, browser/WebView, editor, media files, and model runtime are open together. 64 GB is useful for long 4K projects and heavy multitasking, not required for the detector itself.
CPU selection rule: choose a modern desktop CPU with at least 6 cores / 12 threads for the floor and 8 strong cores for the recommendation. The source does not require an AMD-specific or Intel-specific instruction path; it uses standard Windows x64 Python, FFmpeg, OpenCV/PySceneDetect, and CPU ONNX execution.

Source evidence used

  • backend/clip_cli.py uses CUDA TransNetV2 for GPU mode, NVIDIA decoding for H.264/HEVC/AV1, and PySceneDetect for CPU mode.
  • backend/amv_audio/hardware.py treats CUDA as ready only when PyTorch can actually use it.
  • backend/amv_audio/models.py selects BS-RoFormer for FP16-capable NVIDIA hardware and Kim Vocal 2 otherwise.
  • backend/amv_audio/gpu.py installs the CUDA 12.8 PyTorch wheel for GPU setup.
