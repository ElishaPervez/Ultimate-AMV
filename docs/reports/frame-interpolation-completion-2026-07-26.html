Observable behavior

What is complete

01

Batch-first workspace

The queue remains visible while work runs. A current-file bar and a whole-queue bar show where time is going, and the time estimate starts only after measured work exists.

02

GPU and CPU paths

NVIDIA systems use half-precision model work and hardware H.264 encoding. CPU mode uses full precision and software H.264 encoding, with an honest speed warning in the interface.

03

Audio stays attached

The output receives the original audio stream without re-encoding it. Files without audio continue normally.

04

Hard cuts do not morph

When two neighboring frames are visually unrelated, the earlier frame is held instead of blending the two shots. The final result records how often this happened.

05

Large sources reduce model load

High-resolution frames remain full size in the output, but motion analysis steps down internally when the source would consume excessive graphics memory.

06

Cancellation leaves clean files

Stopping a job kills the active Python and video processes. Completed clips stay; the unfinished file and temporary smoothing files are removed.

Safety and ownership

The app stays MIT and the user’s exports stay recoverable

✓

No TheAnimeScripter source entered the app

The model implementation and weights come from the upstream MIT-licensed Practical-RIFE project. Its required copyright and permission notice are retained.

✓

Model files do not delay app launch

RIFE 4.25 and 4.6 download only when selected. Their exact sizes and content hashes are checked before use.

✓

The bundled runtime remains isolated

The app launches its own Python and its own downloaded video tools. It does not fall back to whatever happens to be installed on the user’s system.

✓

Direct export replaces files only after success

All smoothed temporary outputs must finish successfully before replacement begins. If model work fails, every original export remains unchanged.

✓

The selected container matches the final video

Turning on smoothing moves export to compatible H.264. Choosing an incompatible format turns smoothing off, so a ProRes label cannot silently produce H.264 content.

✓

A failed file does not stop a standalone batch

The queue records that file’s error and continues with the remaining clips. A batch succeeds when at least one output succeeds.

What to click on the target machine
